## ✨ 기능 (Features)

| # | 기능 | 설명 |
|---|------|------|
| 1 | 🔤 **단어 조합기** | 글자 조각으로 6·5글자 단어를 조합하여 낱장·휘장 상자 획득 |
| 2 | 📚 **단어장 정리 도구** | 글자순 정렬, 특정 단어 추출 등 단어장 관리 |
| 3 | 🗄️ **오픈 DB 단어** | 단어 다운로드 및 검색 |
| 4 | 😈 **빌런 단어장 게시** | 빌런 단어장 공유 및 열람 |
| 5 | ⌨️ **타자 연습** | *(예정)* 끄투 단어로 타자 연습 |
| 6 | 🔍 **끄코 정보 조회** | 프로필, 랭킹 등 유저 정보 조회 |
| 7 | ⚔️ **루트전 엔진** | *(예정)* 루트전 최적 플레이 보조 엔진 |

## 🤝 기여 방법 (Contributing)

이 프로젝트는 **오픈 소스**입니다! 기여를 원하시면 아래 단계를 따라주세요 😊

```bash
# 1. 저장소 Fork 후 클론
git clone https://github.com/YOUR_USERNAME/kkuko-utils.git

# 2. 새로운 브랜치 생성
git checkout -b feature/기능명

# 3. 변경 사항 커밋
git commit -am 'feat: 새로운 기능 추가'

# 4. 브랜치 푸시
git push origin feature/기능명
```

이후 **Pull Request**를 생성하여 기여를 제출해 주세요! 🚀
