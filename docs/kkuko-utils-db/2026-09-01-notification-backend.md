# Notification Backend Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `kkuko-utils-db`에 현재 동작과 호환되는 notification PostgreSQL schema, 공개/관리 API, 동시성·인가 test와 이관 도구를 구현한다.

**Architecture:** Notification application service는 port만 사용하고 Kysely repository가 PostgreSQL row와 SQLSTATE를 안정적인 결과로 변환한다. 공개 query와 admin/r4 command를 분리하며, Storage는 아직 Supabase/Next.js에 남기므로 API는 image URL과 참조 여부만 관리한다.

**Tech Stack:** NestJS, `pg`, Kysely, SQL migrations, Jest, Supertest, PostgreSQL integration tests

**Spec:** `../superpowers/specs/2026-09-01-pg-api-strangler-migration-design.md`

## Global Constraints

- 모든 백엔드 경로는 향후 별도 `kkuko-utils-db` 저장소 루트 기준이다.
- `2026-09-01-api-foundation.md` 완료를 선행 조건으로 한다.
- 목록은 중요도, 생성일, ID 내림차순이다.
- 활성 모달은 한국 날짜 마지막 시각을 기준으로 한다.
- 관리자 command는 `admin`, `r4`만 허용한다.
- 모달 기간 중복은 PostgreSQL exclusion constraint가 최종 방어한다.
- 조회 수 증가는 단일 원자 UPDATE이다.
- 초기 update 동시성은 현재와 같은 expected image URL을 사용한다.
- 이미지 upload/delete는 이 계획에서 구현하지 않는다.

- [ ] **Step 2: 실패를 확인한다**

Run: `npm run test:integration -- notifications-migration.integration-spec.ts`

- [ ] **Step 3: SQL migration을 작성한다**

```sql
CREATE TABLE notifications (
  id bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  created_at timestamptz NOT NULL DEFAULT now(),
  title text NOT NULL,
  body text NOT NULL,
  image_url text,
  ends_at timestamptz NOT NULL,
  is_modal boolean NOT NULL DEFAULT false,
  is_important boolean NOT NULL DEFAULT false,
  views bigint NOT NULL DEFAULT 0,
  CONSTRAINT notifications_views_nonnegative CHECK (views >= 0),
  CONSTRAINT notifications_modal_no_overlap
    EXCLUDE USING gist (tstzrange(created_at, ends_at, '[)') WITH &&)
    WHERE (is_modal)
);
```

설계 문서의 세 index를 추가하고 `kkuko_api`에 필요한 SELECT/INSERT/UPDATE/DELETE만 grant한다.

- [ ] **Step 4: Kysely type을 추가한다**

```ts
  body: string;

  ends_at: Date;

  is_important: Generated<boolean>;
  views: Generated<string>;
}
```
